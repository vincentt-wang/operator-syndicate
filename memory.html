禁止 AI 腔文案：「企業通路第一天起」這類直翻不可用，要人話

CSS 規則

Nav 選擇器用 #nav，不用 nav：否則 footer 的 <nav class="ft-nav"> 也會被 fixed 套用，造成浮在頁面頂部的 bug（已發生過）
最小字體 20px：所有正文、說明文字不得小於 1.25rem
Reveal 動畫：用 checkReveal() scroll 事件 + 30ms 立即觸發，不用 IntersectionObserver。class 需搭配 body.will-animate 才隱藏
語言切換：用 textContent swap（applyLang 函式），不用 CSS display:none 切換，否則所有有 data-zh 屬性的元素都會被隱藏

動畫規則

Hero Canvas：55個節點流動網路，橘色連線 + 軌跡殘影。無球形聚合效果（不複製 GVA）。滑鼠有吸引力。
Operator Network Canvas：球形引力邊界（半徑 = min(W,H)×0.38），鄰居彈簧連接，速度阻尼 0.992。滑鼠接觸節點會磁吸跟隨（sticky），離開後恢復漂移。
Globe Canvas：深海軍藍背景（非 GVA 暖白），橘色格線與軌跡。可拖動，2.5秒後自動回到台北位置。

8. 設計決策記錄

2026-06-02

Nav CSS bug 修復：把 nav { position:fixed } 改為 #nav { position:fixed }。原因：nav 通用選擇器把 footer 裡的 <nav class="ft-nav"> 也 fixed 到頂部，導致「Deal Quality/Team/FAQ」浮在右上角，且蓋住 nav 連結無法點擊。根本問題：一個 CSS 選擇器影響了兩個不同的 nav 元素。

2026-06-02

語言切換系統重寫：原版用 [data-zh]{display:none} CSS 隱藏，導致所有有 data-zh 屬性的元素（包括標題）全部不可見。改為 GVA 的 textContent swap 方式：el.textContent = l==='zh' ? el.getAttribute('data-zh') : el.getAttribute('data-en')，只對沒有子元素的元素執行，避免破壞 SVG 按鈕。

2026-06-01

Hero 動畫去球形化：原版複製 GVA 的粒子→球形聚合效果。改為 55 個節點的「流動網路」：有橘色連線、軌跡殘影、滑鼠吸引力，沒有球形收斂。更符合「B2B 連線網路」的概念，且視覺上與 GVA 有明顯差異。

2026-06-01

Operator Network 引力系統：原版節點隨機彈壁，像亂飛的粒子。改為：中心引力（半徑 0.38×min(W,H)），鄰居彈簧連接（每節點 3 個最近鄰），速度阻尼 0.992，速度上限 0.9。節點現在在球形範圍內有秩序地漂移，而非四散。

2026-06-01

Globe 視覺差異化：原版直接複製 GVA 的暖白球形 (#FFF7ED → #FCEEE3)，一看就知道抄的。改為深海軍藍背景（#0A1628 → #060F1E），橘色格線和軌跡（rgba(255,140,66,.08)），符合整體深色高管調性。
