5. 設計規則（必須遵守）

絕對禁止

禁止 Emoji：所有 UI 只用 SVG icon，不用任何 emoji
禁止直接數字：Operator Network section 不顯示「20+」等具體人數
禁止真實公司名稱：全部用化名 Nexia/Oracore/Globex/ACS
禁止顯示高管真實姓名：只用「James C.」等縮寫假名
禁止放真實投資金額或財務數字
禁止中文版有句號：中文標題和 H1 不加標點符號
禁止 AI 腔文案：「企業通路第一天起」這類直翻不可用，要人話

CSS 規則

Nav 選擇器用 #nav，不用 nav：否則 footer 的 <nav class="ft-nav"> 也會被 fixed 套用，造成浮在頁面頂部的 bug（已發生過）
最小字體 20px：所有正文、說明文字不得小於 1.25rem
Reveal 動畫：用 checkReveal() scroll 事件 + 30ms 立即觸發，不用 IntersectionObserver。class 需搭配 body.will-animate 才隱藏
語言切換：用 textContent swap（applyLang 函式），不用 CSS display:none 切換，否則所有有 data-zh 屬性的元素都會被隱藏

動畫規則

Hero Canvas：55個節點流動網路，橘色連線 + 軌跡殘影。無球形聚合效果（不複製 GVA）。滑鼠有吸引力。
Operator Network Canvas：球形引力邊界（半徑 = min(W,H)×0.38），鄰居彈簧連接，速度阻尼 0.992。滑鼠接觸節點會磁吸跟隨（sticky），離開後恢復漂移。
Globe Canvas：深海軍藍背景（非 GVA 暖白），橘色格線與軌跡。可拖動，2.5秒後自動回到台北位置。
